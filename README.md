# Birthday Website for VS Code

This is a plain HTML, CSS, and JavaScript version of the birthday website.

## How to Open

1. Open this `birthday-vscode` folder in Visual Studio Code.
2. Install the VS Code extension called **Live Server**.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.

You can also double-click `index.html`, but Live Server is smoother for testing.

## Easy Personalization

Edit the top of `script.js`:

- `password`
- `sisterName`
- `birthDate`
- `musicSrc`
- `heroLine`
- `letter`
- `galleryPhotos`

Default password:

```text
sister123
```

## Replace Photos and Music

Put your files here:

- `assets/images/`
- `assets/audio/`

Then use paths like:

```js
"assets/images/photo1.jpg"
"assets/audio/song.mp3"
```
